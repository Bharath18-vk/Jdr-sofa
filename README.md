## 🚀 Quick Start

### Prerequisites
- Node.js (v18+)
- npm / pnpm / yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Bharath18-vk/Jdr-sofa.git
cd Jdr-sofa

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
